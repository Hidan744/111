# VinakovLab — портфолио

Одностраничный сайт-портфолио на чистом HTML/CSS/JS (без сборки и зависимостей).
Тема: тёмный техно-минимализм, шрифты Fraunces + JetBrains Mono, анимированная
сеть частиц в hero, карточки проектов с мокапами интерфейса в виде «активных окон».

## Структура

```
index.html      — разметка страницы (все секции)
css/style.css   — стили и анимации
js/main.js      — скролл-эффекты, сеть частиц, меню
```

Открыть локально: просто откройте `index.html` в браузере, либо запустите
любой статик-сервер, например `python3 -m http.server`.

## Что заменить перед публикацией

1. **Имя/роль и контент hero** — `index.html`, секция `<section class="hero">`.
2. **Telegram** — ссылка `https://t.me/ERogx` в `.contact-tg` (секция `#contact`),
   замените на свой юзернейм и подпись `@ERogx в Telegram`.
3. **Проекты** — секция `#work`. Каждая карточка `.work-card` содержит:
   - `.work-window` — мокап интерфейса («активное окно» с заголовком и мини-UI:
     чат, дашборд, конструктор сценариев, поиск, карта маршрута, редактор).
     Разметка и стили мокапов — в `style.css` под комментариями вида
     `/* Aria — chat mock */`; замените текст/цифры внутри на свои или
     нарисуйте новый мокап по тому же принципу (просто HTML/CSS-блоки);
   - теги `.tag`, заголовок, описание, строку `.work-role` (конкретный вклад
     и стек по проекту), метрику `.metric` и ссылку `.work-link`
     (замените `href="#"` на реальную ссылку на демо/репозиторий/кейс).
4. **Навыки/капабилити** — секция `#capabilities`, 6 карточек `.cap-card`.
5. **Favicon** — сейчас встроен как inline SVG data URI в `<head>`, можно заменить на свой файл.

## Цвета и шрифты

Все токены — в начале `css/style.css`, блок `:root`:

- `--accent` — основной акцентный цвет (кислотный лайм `#c9ff3d`);
- `--accent-2` — вторичный акцент (циан, используется в градиентах);
- `--bg`, `--surface` — фон и поверхности;
- шрифты подключены через Google Fonts в `<head>` `index.html`.

## Деплой

Сайт статический — подойдёт GitHub Pages, Vercel, Netlify или любой хостинг
без сервера. Для GitHub Pages: Settings → Pages → Source: ветка с этим кодом,
папка `/ (root)`.
