# AI Specialist — портфолио

Одностраничный сайт-портфолио на чистом HTML/CSS/JS (без сборки и зависимостей).
Тема: тёмный техно-минимализм, шрифты Fraunces + JetBrains Mono, анимированная
сеть частиц в hero, карточки проектов с генеративными обложками.

## Структура

```
index.html      — разметка страницы (все секции)
css/style.css   — стили и анимации
js/main.js      — скролл-эффекты, сеть частиц, копирование email, меню
```

Открыть локально: просто откройте `index.html` в браузере, либо запустите
любой статик-сервер, например `python3 -m http.server`.

## Что заменить перед публикацией

1. **Имя/роль и контент hero** — `index.html`, секция `<section class="hero">`.
2. **Email** — атрибут `data-email` и текст в блоке `#emailCopy` (секция `#contact`).
3. **Ссылки на соцсети** — `href="#"` у `.social-link` в секции `#contact`
   (GitHub / LinkedIn / Telegram).
4. **Проекты** — секция `#work`. Каждая карточка `.work-card` содержит:
   - `data-art="N"` — номер обложки (стили в `style.css`, `.work-card[data-art="N"] .work-art::before`,
     можно поменять цвета градиента под свой проект);
   - теги `.tag`, заголовок, описание, метрику `.metric` и ссылку `.work-link`
     (замените `href="#"` на реальную ссылку на демо/репозиторий/кейс).
5. **Навыки/капабилити** — секция `#capabilities`, 6 карточек `.cap-card`.
6. **Favicon** — сейчас встроен как inline SVG data URI в `<head>`, можно заменить на свой файл.

## Цвета и шрифты

Все токены — в начале `css/style.css`, блок `:root`:

- `--accent` — основной акцентный цвет (кислотный лайм `#c9ff3d`);
- `--accent-2` — вторичный акцент (циан, используется в градиентах);
- `--bg`, `--surface` — фон и поверхности;
- шрифты подключены через Google Fonts в `<head>` `index.html`.

## Деплой

Сайт статический — подойдёт GitHub Pages, Vercel, Netlify или любой хостинг
без сервера. Для GitHub Pages: Settings → Pages → Source: ветка с этим кодом,
папка `/ (root)`.
