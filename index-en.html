Compliance Checklist — data-protection law compliance check

Not a text answer, but a checklist with a status and a citation to the article of law.

Problem

Small businesses don't have an in-house compliance lawyer — violations get discovered only during an audit.

Solution

Built a pipeline where, for every checklist item, Claude looks up the relevant article of the data-protection law and returns a verdict as a strict JSON object — no item can be silently skipped by the model, unlike in a free-form chat.

Result

On a test case for an online store with real violations, the agent correctly flagged all 4 non-compliant items — each with an exact article citation and a quote from the process description.

Role & stack Regulation search · strict JSON output · deterministic verification pipeline

MCP Connector — agent + 1C/CRM integration

Problem
