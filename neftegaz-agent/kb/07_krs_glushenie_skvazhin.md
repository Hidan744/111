# КРС: глушение скважин

Источник: Технологическая инструкция «Технические требования и
организация работ по глушению скважин» (внутренняя ТИ добывающего
общества). Формулы и коэффициенты — из этого документа, не общая теория.

## Расчёт плотности жидкости глушения (ЖГ)

При полной замене скважинной жидкости в 1 цикл:
```
ρжг = (Рпл × (1 + П)) / (g × H) × 10³
```
где:
- ρжг — плотность жидкости глушения, г/см3;
- Рпл — пластовое давление, МПа;
- П — коэффициент безопасности работ (зависит от глубины, коэффициента
  продуктивности, газосодержания) — **для этого предприятия принят
  равным 0,05 (5%)**; в особых условиях может быть определён отдельно.
- H — глубина эксплуатируемого пласта по вертикали, м (при нескольких
  объектах — глубина верхнего пласта по наивысшей точке интервала
  перфорации).
- g — ускорение свободного падения, 9,81 м/с2.
- Перевод давления: 1 физическая атмосфера = 0,101325 МПа.

Расчёт истинного пластового давления по замеренному избыточному
давлению на устье (закрытая задвижка):
```
Рпл = (ρ × g × H) / 10³ + Ризб
```
где ρ — фактическая плотность жидкости в скважине, г/см3; Ризб —
устьевое избыточное давление, МПа.

Расчёт максимального ожидаемого давления на устье:
```
Рожид = Рпл − (ρ × g × h) / 10³
```
(та же логика, что и в файле про категорию скважины: избыточное
давление на устье = пластовое минус вес столба жидкости в стволе).

Прогнозное пластовое давление берётся из карт изобар и уточняется
дополнительно по: динамике устьевого давления при закрытой задвижке,
статическому уровню, ЖГ на соседних скважинах, ГДИС, материальному
балансу/прокси-моделированию.

## Расчёт объёма жидкости глушения

```
Vжг = (Vэк − Vнкт − Vшт) × 1,1
```
- Vэк = (π×D²/4) × H — объём эксплуатационной колонны, м3 (D — внутренний
  диаметр ЭК, м).
- Vнкт = (π×(d² − d1²)/4) × Hсп — объём, вытесняемый металлом НКТ (d, d1 —
  внешний/внутренний диаметр НКТ, Hсп — глубина спуска насоса).
- Vшт — объём, вытесняемый штангами (если есть).
- 1,1 — коэффициент запаса.

Количество циклов глушения:
```
N = H2/H1 + 1  (округление вверх до целого)
```
H1 — глубина от устья до места циркуляции (насос/хвостовик/сбивной
клапан), H2 — от места циркуляции до верхних отверстий перфорации.

Если пластов несколько и расстояние между ними >50 м — H берётся до
кровли пласта с БОЛЬШИМ пластовым давлением.

## Типы жидкостей глушения (ЖГ) и их плотности

- **NaCl (хлористый натрий)** — до 1,18 г/см3. Дёшево, доступно, но может
  вызвать кольматацию ПЗП на заглинизированных коллекторах (набухание
  глин) — снижение проницаемости по нефти до 46% при многократной
  прокачке. Обязательно + ингибитор коррозии/солеотложений; на глинистых
  коллекторах — + ингибитор набухания глин.
- **KCl (хлористый калий)** — до 1,14 г/см3. Не вызывает набухания глин
  (лучше NaCl для чувствительных коллекторов). + ингибитор
  коррозии/солеотложений обязательно.
- **CaCl2 (хлористый кальций)** — до 1,35 г/см3. Восстановление
  проницаемости по нефти после фильтрации в среднем не выше 30-35% —
  обязательно + ингибитор коррозии, солеотложений, гидрофобизатор.
- **Ниткал / нитрат кальция «Премиум» / СГС-15** — насыщенные растворы до
  1,6 г/см3; в комбинации с CaCl2 — до 1,6 г/см3 (t кристаллизации ниже
  −15°C); в комбинации с галитом — до 1,48 г/см3. Риск выпадения солей
  (кальцит, гипс) при контакте с водами, содержащими гидрокарбонат-/
  сульфат-ионы — обязательно ингибировать.
- **Комбинированные растворы** (галит + нитрат кальция) — максимум
  1,35 или 1,48 г/см3 в зависимости от рецептуры; меньше солеотлагающих
  ионов кальция, чем чистый CaCl2/нитрат той же плотности.
- Общее требование: ЖГ должна быть негорючей, взрывопожаробезопасной,
  нетоксичной.

## Блокирующие составы (БСГ)

Назначение: не допустить ухода ЖГ в пласт — используются при
многопластовой залежи, высоком газовом факторе, скважинах после ГРП,
суперколлекторах (>1 Дарси), АНПД/АВПД.

```
V(БСГ) = 0,001 × Vуд × H + Vизб
```
- H — от текущего забоя до верхнего уровня установки БСГ (обычно на
  150 м выше верхних отверстий перфорации, но не выше низа колонны НКТ
  минус 10-50 м — граница БСГ не должна перекрывать низ НКТ).
- Vуд — удельный внутренний объём ЭК, дм3/м.
- Vизб — запас на смачивание стенок + продавку в пласт (отдельная
  формула, зависит от вскрытого интервала перфорации и коэффициентов
  К=0,05 для наклонно-направленных/вертикальных, К=0,01 для
  горизонтальных скважин на метр интервала).

Типы: обратные эмульсии (ИНЭР/ИЭР/ГЭС, плотность 0,9-1,18 г/см3, не
хранить в мороз ниже −20°C дольше 2 суток); БСГ-галит и БСГ-МК (гелевая
суспензия с твёрдой фазой — соль или микрокальцит, для шунтирования
трещин/пор). **Плотность БСГ должна превышать плотность ЖГ минимум на
10 кг/м3.**

Запрещено добавлять в БСГ реагент без проверки совместимости жидкостей.

## Ингибиторы

- Гидрофобизаторы / ингибиторы набухания глин — сохраняют фазовую
  проницаемость по нефти в чувствительных к минеральному составу
  пластах.
- Ингибиторы солеотложений — обязательны для растворов на основе CaCl2,
  нитратов и комбинированных, во избежание осадкообразования.
- Ингибиторы коррозии — обязательны для высокоминерализованных
  растворов.

## Выбор ЖГ по группе объекта (геология конкретного предприятия)

Объекты разработки поделены на 3 группы (по литологии, проницаемости,
склонности глин к набуханию — конкретное отнесение объекта к группе
берётся из внутреннего справочника предприятия, аналог — по ближайшему
месторождению при отсутствии данных):

- **Группа I** (нижний мел, кроме Ачимовской свиты) — глушение не
  осложнено. ρ<1,0 → БСГ (ИНЭР) + пресная вода + ингибиторы; ρ 1,0-1,18 →
  NaCl + ингибиторы; ρ>1,18 → CaCl2/Ниткал/СГС-15/комбинированные (до
  1,35-1,48) + гидрофобизатор + ингибиторы солеотложений/коррозии.
- **Группа II** (низкопроницаемые, малая набухаемость) — та же логика по
  плотности, но с обязательным гидрофобизатором уже начиная с ρ<1,0, и с
  БСГ-МК/БСГ-галит при ρ>1,18.
- **Группа III** (юра, ачимовская пачка — низкая проницаемость, высокое
  содержание глин, чувствительность к минерализации) — для ρ 1,0-1,14
  используется именно KCl (не NaCl — глины чувствительнее), при ρ>1,14
  допустимы ИНЭР/БСГ-МК/БСГ-галит и весь спектр солевых растворов с
  обязательным ингибированием.

Общее правило: если текущее пластовое давление ниже гидростатического —
обязательна постановка блокирующей пачки независимо от группы.

## Осложняющие факторы

- Глубокая депрессия (Рзаб ≤ 50 атм) создаёт депрессионную воронку —
  пластовое давление в план-заказе даётся "на контуре питания", не на
  забое.
- Одновременная эксплуатация нескольких пластов — единая плотность ЖГ не
  подходит всем сразу → риск ГНВП в стволе.
- Аномальность пластового давления (коэффициент КА = Рпл.факт / Рпл.гидростат.):
  КА ≤ 0,8 — аномально низкое; 0,8 < КА ≤ 1,0 — пониженное;
  1,0 < КА ≤ 1,05 — нормальное. При КА ≤ 1,0 поддержание уровня ЖГ на
  устье не требуется — работать через поддержание безопасного
  статического уровня (см. отдельный файл про статический уровень).

## Повторное / очередное глушение / промывка — как отличить

- **Повторное глушение** — глушение уже заглушенной скважины при первых
  признаках ГНВП, БЕЗ объективных осложняющих факторов (обычно
  технологическая причина — нарушение регламента глушения бригадой).
- **Очередное глушение** — запланировано заранее планом работ из-за
  объективного осложняющего фактора (депрессионная воронка, работы после
  ГРП/ОПЗ и т.п.).
- Критерий "глушение" (повторное/очередное) vs "промывка": замена >80%
  объёма скважины и/или пересчёт плотности ЖГ = глушение; замена <80% без
  пересчёта плотности = промывка (для предупреждения первых признаков
  ГНВП, не факт ГНВП).

При отклонении параметров (избыточное давление, признаки ГНВП) —
бригада ТКРС обязана сообщить в геолого-технологическую службу (ГТС),
стравить газ, при необходимости разрядить скважину, зафиксировать замер
избыточного давления с фотопривязкой к дате/времени, и только после
этого проводить повторное/очередное глушение с оформлением акта с
указанием конкретной причины (некорректные данные Рпл, влияние
нагнетательных скважин, нарушение технологии бригадой, негерметичность
оборудования и т.д. — не общая формулировка "проблема с давлением").
