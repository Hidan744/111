# КРС: определение пластового давления (для ВНС/ЗБС и ТКРС)

Источник: методические указания «Организация работ по определению и
выдаче пластового давления при ВНС и ЗБС» (внутренний документ).

## Расчёт Рпл по данным затрубного давления и уровня

**Скважина, дающая безводную нефть:**
```
Рпл = Ру + {(Нприв − Lприв) − (Нуров − Lуров)} × ρн / 10,2
```
- Рпл — давление на глубине приведения (ВНК или ВДП), кгс/см2
- Ру — затрубное давление на устье, кгс/см2
- Нприв/Lприв, Нуров/Lуров — глубины приведения и уровня жидкости по
  вертикали, м
- ρн — плотность нефти в пластовых условиях, г/см3

**Скважина с обводнённой продукцией:**
```
Рпл = Ру + [{(Нсп−Lсп) − (Нуров−Lуров)} × {ρн×(1−nв/100) + ρв×nв/100} / 10,2
      + {(Нприв−Lприв) − (Нсп−Lсп)} × ρв / 10,2]
```
где nв — обводнённость продукции перед остановкой скважины (%), ρв —
плотность пластовой воды.

**Условность по обводнённости для этого расчёта:**
- если фактическая обводнённость перед остановкой 1-40% → в расчёт
  берётся **40%** (не фактическое значение);
- если 40-95% → берётся фактическое промысловое значение;
- если >95% → берётся **95%**.

## Классификация методов определения пластового давления

По способу замера:
- **Прямые** — глубинным манометром на кровлю пласта/верхние отверстия
  перфорации (точнее).
- **Косвенные** — пересчёт через гидростатическое давление столба
  жидкости (погрешность зависит от точности оценки плотности затрубной
  жидкости и глубины межколонного уровня).

По технологии:
- **Промыслово-диагностические (простые)** — только замер Рпл на
  остановленной скважине (глубинные манометры, эхолот на статический
  уровень, замер Ризб).
- **Гидродинамические (сложные)** — прослеживание динамики от рабочего
  до восстановленного давления; дополнительно дают параметры пласта.
  Включают: КВД/КВУ (кривая восстановления давления/уровня), КПД
  (кривая падения давления), термогидродинамические исследования, метод
  установившихся отборов (ИД), мини-ГРП, гидропрослушивание.

Дополнительные источники текущего Рпл:
- **Мини-ГРП** — берётся из отчёта подрядчика, расчёт по методу Хорнера.
- **ГИС** — статическое забойное давление из фонового замера барометра
  при других работах (отбивка забоя, испытание пласта и т.п.).

## Пересчёт давления с глубины замера на глубину ВДП

Общая логика: давление — это вес столба жидкости, поэтому замеренное на
одной глубине давление нужно скорректировать на разницу высот столба до
целевой глубины (ВДП — верхние дыры перфорации).

**Общий случай:**
```
Рвдп = Рзам + [(Нвдп − Нсп) × ρфл] / 10
```
где ρфл — плотность флюида в стволе между глубиной замера и ВДП, г/см3.

**Оценка ρфл по двум точкам замера** (если записана эпюра давления по
глубине через равные интервалы, например каждые 200 м):
```
ρфл = (Р2 − Р1) × 10,332 / (Н2 − Н1)
```

**Если эпюра недоступна** (например, замер по ТМС) — для работающей
добывающей скважины плотность берётся по факту обводнённости:
```
Рвдп = Рзам + [(Нвдп − Нсп) × (ρн×(1−обв) + ρв×обв)] / 10
```
(ρн — плотность нефти в пластовых условиях).

**Для остановленной скважины** — та же формула, но ρн берётся **в
поверхностных условиях** (не в пластовых).

**Важно:** использование поверхностных/пластовых плотностей в этих
формулах — рекомендательное, они не учитывают растворённый газ в стволе.
Для скважин с сильным газопроявлением нужно учитывать изменение
плотности по стволу отдельно.

## Оценка Рпл по данным глушения (без учёта коэффициента запаса)

Если известна плотность ЖГ, которая исторически применялась (например,
последний раз при заглушенной скважине без осложнений), пластовое
давление можно оценить обратным счётом:
```
Рпл = ρж × Н × 9,8 × 10⁻⁶
```
С учётом замера избыточного давления до стабилизации:
```
Рпл = ρж × Н × 9,8 × 10⁻⁶ + Ризб
```
Отсутствие циркуляции при глушении — сигнал, что пласт поглощает
жидкость, то есть плотность ЖГ была подобрана с избытком (Рпл ниже, чем
предполагалось). Также можно использовать изменение статического уровня
в процессе ТКРС (рост Нст после первых суток поглощения — признак
восстановления Рпл в околоскважинной зоне).

**Примечание:** формула плотности ЖГ через Рпл (с коэффициентом
безопасности П) — см. файл про глушение скважин; там она приведена
точно по действующей версии технологической инструкции.

## Индикаторная диаграмма (ИД) — общий метод

Строится по 5-7 установившимся режимам работы скважины (глубинный
манометр на известной глубине): для каждого режима — забойное давление
(Рзаб = давление на приборе + вес столба жидкости от прибора до забоя)
и дебит/приёмистость (Q).

- Точки наносятся на график Рзаб(Q). Как правило получаются **два
  участка с разным наклоном** (излом графика).
- **Продолжение прямой первого участка до пересечения с осью Q=0** даёт
  **пластовое давление**.
- **Точка излома (пересечения двух прямых)** — давление смыкания или
  раскрытия трещины автоГРП (в зависимости от того, восходящий это
  излом или нисходящий).
- **Наклон каждого участка** = коэффициент приёмистости/продуктивности
  для этого режима (разный до и после трещины).

Коэффициент продуктивности (общая формула, без привязки к трещине):
```
Кпрод = Qж / (Рпл − Рзаб)
```

## Приоритет источников данных при выдаче Рпл

**Для ВНС/ЗБС в районе действующих скважин (по убыванию приоритета):**
1. Данные ГДИС.
2. Данные ЦДНГ по скважинам окружения (Ризб, Нст).
3. Карты изобар (материальный баланс, прокси-модель).
4. Данные по ЖГ при ТКРС окружения и Нст на запуске после ТКРС.

**Для новых районов ВНС (нет истории по окружению):**
1. Рпл из проектно-технологической документации.
2. Данные по раствору бурения на этой кустовой площадке.
3. Данные по раствору бурения на ближайших кустовых площадках.

## Остановка нагнетательных скважин перед вскрытием пласта

Рекомендуемые сроки остановки/разрядки перед вскрытием целевого или
транзитного пласта:
- **14 суток** — юрские и ачимовские пласты.
- **7 суток** — меловые пласты.

После остановки — комиссионный замер избыточного давления (акт
подписывают супервайзер по бурению, геолог ЦДНГ, специалист УпоРМ). Если
за сутки нет тенденции снижения избыточного давления — скважину нужно
обвязать и открыть на разрядку с замером дебита.
