# Расчётный блок

> ВАЖНО: формулы ниже — это стандартные общепромысловые методики
> (базовый уровень, который используется как отправная точка).
> Перед продажей клиентам обязательно свериться со своими внутренними
> методиками/РД — если в твоей практике (или на твоём предприятии,
> см. проект нефтяного бота) приняты другие коэффициенты или формулы,
> замени их здесь на реальные.

## 1. Дебит нефти с учётом обводнённости

Базовая формула:

```
Q_нефти = Q_жидкости × (1 − f_в)
```

где:
- Q_жидкости — измеренный дебит жидкости (нефть + вода), м3/сут
- f_в — обводнённость, доля единицы (если задана в % — разделить на 100)

Дебит воды, соответственно:
```
Q_воды = Q_жидкости × f_в
```

**Что важно проверять:** обводнённость обычно растёт со временем разработки —
разовое значение малоинформативно без динамики за несколько месяцев.

## 2. Прогноз добычи (метод падения дебита / кривые Арпса)

Три типовых режима падения дебита во времени:

- **Экспоненциальный** — постоянный темп падения:
  `Q(t) = Q0 × e^(−D×t)`
- **Гиперболический** — темп падения замедляется со временем:
  `Q(t) = Q0 / (1 + b×D0×t)^(1/b)`
- **Гармонический** — частный случай гиперболического при b = 1:
  `Q(t) = Q0 / (1 + D0×t)`

где Q0 — начальный дебит, D (D0) — начальный темп падения, b — коэффициент
кривизны (обычно 0–1 для нефтяных скважин).

**Практический момент:** для первой версии продукта не обязательно давать
модели право решать, какой из трёх режимов использовать — лучше явно
указывать в промпте, какой тип кривой принят на объекте (это обычно уже
определено предыдущими исследованиями скважины).

## 3. Эффект ГТМ (геолого-технических мероприятий)

### ОПЗ (обработка призабойной зоны)
Цель — снизить скин-фактor (загрязнение призабойной зоны), что увеличивает
продуктивность скважины. Упрощённая оценка эффекта через коэффициент
продуктивности:

```
Q_после = Q_до × (ln(Rk/rc) + S_до) / (ln(Rk/rc) + S_после)
```

где Rk — радиус контура питания, rc — радиус скважины, S — скин-фактор
до/после обработки. Это упрощение (формула Дюпюи со скином) — для точной
оценки нужны гидродинамические исследования до и после.

### ГРП (гидроразрыв пласта)
Эффект оценивается через рост эффективного радиуса скважины за счёт
созданной трещины — требует данных о полудлине трещины и проводимости.
Для черновой оценки без детального моделирования обычно используют
статистику по аналогичным скважинам того же пласта (если есть история ГРП
на соседних скважинах — сравнение даёт более надёжный прогноз, чем чистая
теория).

### ИДН (интенсификация добычи нефти)
Общий термин для методов увеличения дебита без изменения конструкции
скважины (химические, тепловые и др. обработки) — эффект считается
индивидуально по типу воздействия, единой формулы нет.

### ВБД (ввод скважин из бездействия)
Здесь расчёт — это, по сути, прогноз ожидаемого дебита при запуске
простаивавшей скважины, с поправкой на то, сколько времени она бездействовала
(возможное снижение проницаемости призабойной зоны за время простоя).

---

**Как это использовать в промпте:** просить модель явно указывать, какую
из формул/методик она применила и какие значения подставила — это ключевое
требование из ядра методологии (файл 00), чтобы инженер мог проверить расчёт
глазами, а не просто поверить цифре.
