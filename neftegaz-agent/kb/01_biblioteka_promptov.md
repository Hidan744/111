# Библиотека промптов — нефтегазовый модуль

## Категория 1: Диагностика

**Промпт-шаблон:**
```
Скважина №[НОМЕР], [ТИП: добывающая/нагнетательная].
Текущие показатели: дебит жидкости [Qж] м3/сут, обводнённость [f_в] %,
пластовое давление [Рпл] атм, забойное давление [Рзаб] атм,
динамика за последние [N] месяцев: [ОПИСАНИЕ ТРЕНДА].

Определи: (1) вероятные причины текущего состояния скважины,
(2) на какие ГТМ стоит обратить внимание, (3) какие ещё данные нужны
для более точного диагноза.
```

## Категория 2: Расчёт

**Промпт-шаблон:**
```
По скважине №[НОМЕР] известно: дебит жидкости [Qж] м3/сут,
обводнённость [f_в] %, плотность нефти [ρ] кг/м3.

Посчитай дебит нефти с учётом обводнённости. Покажи формулу и подстановку
значений, не только итоговое число.
```

*(См. файл 02_raschety_debit_gtm.md — там методика, на которую этот промпт опирается)*

## Категория 3: Нормативная проверка

**Промпт-шаблон:**
```
Опиши процесс/ситуацию: [ОПИСАНИЕ].
Проверь на соответствие требованиям Ростехнадзора к эксплуатации ОПО
(опасных производственных объектов) в части [КОНКРЕТНАЯ ОБЛАСТЬ —
например, фонтанная арматура, факельные системы, и т.д.].

Укажи: (1) какие требования применимы, (2) есть ли явные несоответствия
по описанию, (3) что нужно уточнить или проверить документально.
```

## Категория 4: Подбор оборудования

**Промпт-шаблон:**
```
Прогнозные параметры скважины после ГТМ: дебит жидкости [Qж] м3/сут,
обводнённость [f_в] %, глубина спуска [H] м, диаметр эксплуатационной
колонны [D] мм.

Предложи типы механизированной добычи (ШГН/ЭЦН/газлифт), подходящие под
эти параметры, с обоснованием и ограничениями каждого варианта.
```

## Категория 5: Генерация документа/отчёта

**Промпт-шаблон:**
```
На основе расчёта выше (или вставленных данных) сформируй короткую
служебную записку для начальника цеха: (1) что обнаружено,
(2) рекомендация, (3) что нужно для реализации. Деловой стиль,
без воды, максимум 1 страница.
```

## Категория 6: Обучение стажёра

**Промпт-шаблон:**
```
Объясни стажёру-геологу простым языком: что такое [ТЕРМИН — например,
"обводнённость скважины" или "ГРП"], почему это важно контролировать,
и что произойдёт, если этот параметр проигнорировать.
```
