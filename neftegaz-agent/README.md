# Нефтегазовый ИИ-ассистент — MVP на Yandex AI Studio

## Что это

Прототип "Уровня 2" из нашего плана: ИИ-ассистент с базой знаний
(методология + расчёты + нормативка + подбор оборудования + обучение),
работающий через YandexGPT. Пока без Telegram-бота — просто консольный
диалог для теста, что ассистент вообще ведёт себя правильно.

## Структура файлов

```
neftegaz-agent/
├── kb/                          ← база знаний (промпт-библиотека)
│   ├── 00_metodologiya_yadro.md    ← ядро, не меняется между нишами
│   ├── 01_biblioteka_promptov.md
│   ├── 02_raschety_debit_gtm.md
│   ├── 03_normativka.md
│   ├── 04_podbor_oborudovaniya.md
│   └── 05_obuchenie_stazhera.md
├── bot.py                       ← основной скрипт
├── requirements.txt             ← зависимости Python
├── .env.example                 ← шаблон для ключей доступа
└── README.md                    ← этот файл
```

## Шаг 1. Установи Python (если ещё нет)

Скачай с https://www.python.org/downloads/ — версия 3.10 или новее.
При установке на Windows обязательно поставь галочку "Add Python to PATH".

## Шаг 2. Получи API-ключ и Folder ID в Yandex AI Studio

Ты уже вошёл в AI Studio — там нужно:

1. В правом верхнем углу нажать **"Создать API-ключ"** (Create API key)
2. Сохранить выданный ключ — он показывается только один раз
3. Найти **Folder ID** (ID каталога) — обычно виден в интерфейсе AI Studio
   рядом с названием проекта/каталога, либо в разделе настроек каталога

## Шаг 3. Распакуй проект и открой терминал в этой папке

- Windows: открой папку, в адресной строке проводника напиши `cmd` и нажми Enter
- Mac: открой Terminal, введи `cd ` (с пробелом) и перетащи папку в окно терминала, нажми Enter

## Шаг 4. Установи зависимости

```
pip install -r requirements.txt
```

Если `pip` не находится — попробуй `pip3` или `python -m pip install -r requirements.txt`.

## Шаг 5. Настрой ключи доступа

1. Скопируй файл `.env.example` и назови копию `.env`
2. Открой `.env` в любом текстовом редакторе (Блокнот подойдёт)
3. Вставь свой реальный API-ключ и Folder ID вместо плейсхолдеров

## Шаг 6. Запусти

```
python bot.py
```

Если всё настроено верно — увидишь приглашение "Нефтегазовый ассистент готов".
Пиши вопрос, например:

```
Скважина №14, добывающая. Дебит жидкости 45 м3/сут, обводнённость 62%.
Посчитай дебит нефти.
```

Для выхода напиши `exit`.

## Что дальше (после того, как MVP отработал на тестовых вопросах)

1. **Прогнать 5-10 реальных кейсов** из твоей практики — сверить, не
   ошибается ли модель, не путает ли формулы. Если база знаний неточна —
   править файлы в `kb/`, а не код `bot.py`.
2. **Обернуть в Telegram-бота** — тут можно использовать тот же `bot.py`
   почти без изменений, просто вместо `input()`/`print()` подключить
   библиотеку типа `aiogram` или `python-telegram-bot`, которая будет
   получать сообщения из Telegram и вызывать ту же функцию генерации ответа.
3. **Клонировать под новую нишу** — скопировать папку проекта, оставить
   `00_metodologiya_yadro.md` как есть, а остальные файлы в `kb/` заменить
   на новый отраслевой модуль (используй мета-промпт в конце файла
   `00_metodologiya_yadro.md`, чтобы сгенерировать черновик).

## Важно перед продажей клиентам

Формулы в `02_raschety_debit_gtm.md` — это стандартные общепромысловые
методики для старта, не проприетарная методика конкретного предприятия.
Обязательно сверь их со своей практикой (в том числе с наработками из
проекта нефтяного бота) и поправь файл под реальные принятые у тебя
коэффициенты и формулы, прежде чем показывать продукт клиентам.
